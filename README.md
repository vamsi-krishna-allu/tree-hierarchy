# Hierarchy

A Java library for representing and filtering tree/forest structures using DFS-ordered arrays.

## Project Structure

```
src/
└── main/java/com/example/hierarchy/
│   ├── Hierarchy.java            # Interface defining the data structure
│   ├── ArrayBasedHierarchy.java  # Array-backed implementation
│   └── HierarchyFilter.java      # Filter utility
└── test/java/com/example/hierarchy/
    └── HierarchyTest.java        # JUnit 5 tests
```

## Running Tests

```bash
mvn test
```

## Requirements

- Java 21+
- Maven 3.x
